# Module library index

This directory contains the AVM-style Bicep modules for the AKS and Radius platform.

- `aks/cluster` - AKS managed cluster
- `aks/nodepool` - AKS user node pools
- `network/virtual-network` - VNet and subnets
- `monitoring/log-analytics` - Log Analytics workspace
- `container-registry/acr` - Azure Container Registry
- `identity/user-assigned-identity` - managed identity
- `radius/environment` - Radius environment
- `radius/application` - Radius application
